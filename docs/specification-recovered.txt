Implementation  Phases:  Perception-Plus-Navigation  
Setup  
●  Construct  the  building  world,  place  the  markers,  run  SLAM  once,  and  save  a  static  map  
for
 
the
 
mission

Navigation  
●  Localize  on  the  saved  map  using  AMCL.  ●  Drive  a  patrol  route  using  Nav2  (via  waypoints  from  a  config  file  or  the  Nav2  
waypoint-follower
 
API).
 
Perception  Node  
●  Detect  ArUco  markers  (cv2.aruco)  or  a  target  color  (HSV  threshold  +  contour)  on  the  
camera
 
stream.
 ●  On  detection,  estimate  the  marker  pose  relative  to  the  camera,  use  TF  to  transform  it  
into
 
the
 
map
 
frame
 
(camera →  base →  map),  and  publish  detected  markers  to  RViz.  
Victim-Registry  Node  
●  Deduplicate  detections  (the  same  ID  or  nearby  position  counts  as  one).  ●  Provide  a  ROS2  service  that,  upon  request,  returns  the  full  list  of  victims  with  their  map  
coordinates.
